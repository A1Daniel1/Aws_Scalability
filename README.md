# AWS Scalability - HTTP Server

A Java-based HTTP server project built with Spring Boot and Maven.

## What's included

- **Custom HTTP Server** – Handles GET and POST requests, serves dynamic HTML forms, and returns JSON responses with query string parsing.
- **URL Reader** – Utility to read and fetch content from URLs.
- **Echo Server/Client** – Basic socket communication examples.

## Requirements

- Java 17
- Maven

## Run

```bash
mvn spring-boot:run
```

The server listens on port `35000`.
